# 音频层设计模板
# 适用于即梦/Jimeng AI 视频生成
# 音频层独立于画面层，作为第三维度存在

## 一、音频层结构

每个片段的音频输出格式：

```
【音频设计】
├─ 环境音层 (AMB)
├─ 音效层 (SFX)
├─ 语音层 (VOICE)
└─ 音乐层 (BGM)
```

---

## 二、环境音层 (AMB) — 必须保留

### 基础规则
- 保留真实环境音、物件音、电话声、脚步声、呼吸声等
- 禁止新增背景音乐、配乐、BGM（音乐层单独控制）
- 环境音应与画面场景匹配

### 场景化环境音标准词库

#### 室内场景
| 场景 | 关键词 |
|------|--------|
| 客厅 | 木地板轻微吱呀、窗外隐约街道声、挂钟滴答、老式吊扇转动 |
| 卧室 | 床单窸窣、空调低鸣、窗帘轻微拍打、隔壁隐约人声 |
| 办公室 | 键盘敲击、打印机运转、空调出风口、电话等待音 |
| 餐厅 | 碗筷轻碰、酒杯碰撞、背景低语、厨房锅铲声 |
| 酒吧/KTV | 低频音乐穿透、玻璃碰撞、笑语嘈杂、吧台器具声 |

#### 室外场景
| 场景 | 关键词 |
|------|--------|
| 街道 | 汽车驶过、远处喇叭、行人脚步、风声、树叶沙沙 |
| 雨天街道 | 雨滴敲打地面、车窗雨刷、积水溅起、汽车引擎 |
| 乡村/田野 | 蛙鸣蝉噪、鸟叫、风吹麦浪、溪水潺潺 |
| 海边 | 海浪拍岸、海鸥叫声、海风呼啸、远处汽笛 |
| 夜晚 | 蟋蟀声、远处狗吠、风声、夜虫低鸣 |

#### 特殊环境
| 场景 | 关键词 |
|------|--------|
| 雨中 | 持续雨声、屋顶滴答、水坑溅水、雨刷节奏 |
| 雷雨 | 雷声轰鸣、雨势加大、窗户震动、闪电后的寂静 |
| 雪夜 | 脚下积雪咯吱、风雪呼啸、万籁俱寂 |
| 废墟/空旷 | 回声、碎石掉落、风穿过空洞、老旧结构吱呀 |

---

## 三、音效层 (SFX) — 时间码精确

### 格式标准
```
[时间码] 音效类型 | 持续时长 | 强度 | 备注
```

### 示例
```
[00:00-00:02] 脚步声-木地板 | 2s | 清晰 | 近景可闻
[00:02-00:05] 心跳声渐强 | 3s | 微弱→强烈 | 情绪铺垫
[00:05-00:06] 手机震动 | 1s | 强烈 | 打破沉默
```

### 核心音效分类

#### 动作音效
| 类别 | 关键词 |
|------|--------|
| 打击类 | 拳头击中、肉体碰撞、玻璃碎裂、木头断裂 |
| 摩擦类 | 脚步急促、布料撕裂、金属摩擦、玻璃划痕 |
| 机械类 | 引擎启动、门锁咔嗒、按键点击、武器上膛 |
| 物体类 | 纸张翻动、书本合上、钥匙碰撞、硬币落地 |

#### 反应音效
| 类别 | 关键词 |
|------|--------|
| 呼吸类 | 急促呼吸、屏住呼吸、叹息、长舒一口气 |
| 惊讶类 | 倒吸气、惊呼、愣住、呆住 |
| 情绪类 | 抽泣、哽咽、轻笑、冷笑、苦笑 |

#### 物件音效
| 类别 | 关键词 |
|------|--------|
| 门/窗 | 关门声、推窗声、敲门声、锁门声 |
| 家具 | 椅子移动、床铺吱呀、抽屉开合 |
| 电子设备 | 手机铃声、消息提示音、电话铃声、闹钟 |
| 餐具 | 碗筷碰撞、杯子放下、酒杯碰撞、干杯 |

---

## 四、语音层 (VOICE) — 台词同期声

### 规则
- 台词必须来自原剧本，不新增、不改写
- VO/旁白独立轨道，不与对话混音
- 电话通话双方音色应有区分（距离感/设备感）

### 语音处理关键词
| 类型 | 描述 |
|------|------|
| 近距离对话 | 声音饱满、气息可闻、细节丰富 |
| 远距离喊话 | 声音略有衰减、回声、环境遮蔽 |
| 电话/VO | 设备质感（手机压限感/画外音空间感） |
| 窃窃私语 | 气息声明显、唇齿音清晰、音量极低 |
| 喊叫/怒吼 | 音量爆发、穿透感、可能有轻微失真 |

---

## 五、音乐层 (BGM) — 时间码+节拍同步

### 格式标准
```
[进入时间] 音乐描述 | 节奏(BPM) | 情绪 | 节拍位置
```

### 示例
```
[00:05] 弦乐渐入 | 60BPM | 悬疑紧张 | -
[00:12] 低频脉冲 | 75BPM | 压迫感 | -
[00:15] 钢琴独奏 | 55BPM | 悲伤回忆 | 节拍同步: 00:15;00:17;00:19
[00:20] 鼓点爆发 | 140BPM | 动作紧张 | 鼓点对齐剪辑点
```

### 节拍同步标注
当视频剪辑点与音乐节拍需要对齐时：
```
节拍同步: [时间点1];[时间点2];[时间点3]
例: 节拍同步: 00:03;00:06;00:09;00:12  (每3秒一个强拍)
```

### 音乐情绪关键词库

#### 紧张/悬疑
| 类型 | 描述 |
|------|------|
| 低频脉冲 | 持续低频震动、BPM 60-80、压迫感递增 |
| 弦乐锯齿 | 不和谐音程、渐强弓法、BPM 不规则 |
| 时钟滴答 | 规律节拍+留白、BPM 40-60、制造等待感 |
| 电子脉冲 | 合成器音色、节奏机械、BPM 100-140 |

#### 悲伤/抒情
| 类型 | 描述 |
|------|------|
| 钢琴独奏 | 单音旋律、BPM 40-70、延音踏板 |
| 弦乐群奏 | 和声铺底、BPM 50-80、情感饱满 |
| 民乐/古风 | 二胡/琵琶/古筝、BPM 缓、意境悠远 |
| 环境白噪音+ | 雨声/风声/海浪+极简旋律、BPM 不定 |

#### 动作/战斗
| 类型 | 描述 |
|------|------|
| 鼓点爆发 | 强节奏打击、BPM 140-180、鼓点对齐动作 |
| 铜管激昂 | 铜管齐奏、BPM 120-160、冲锋感 |
| 电子节拍 | 合成器鼓组、BPM 130-160、科技感 |
| 交响爆发 | 乐团总奏、BPM 100-140、高潮段落 |

#### 浪漫/温馨
| 类型 | 描述 |
|------|------|
| 弦乐抒情 | 和谐和弦、BPM 60-90、温暖流动 |
| 钢琴+吉他 | 双乐器织体、BPM 70-100、清新自然 |
| 电子氛围 | 合成器Pad、BPM 不定、空灵飘渺 |
| 民族乐器 | 手风琴/口琴/BossaNova、BPM 80-120 |

## 六、完整音频设计示例

### 场景：雨夜老宅告别

```
@李明 / @张华

【音频设计】

├─ 环境音层 (AMB)
│   └─ 持续: 雨声淅沥(小雨到中雨)、远处雷声隐约、老宅木质结构轻微吱呀
│
├─ 音效层 (SFX)
│   └─ [00:01-00:02] 脚步踩在木地板上 | 1s | 清晰 | 近景
│   └─ [00:04-00:05] 手机震动无声(屏幕亮光可见) | 1s | 微弱 | 桌上手机
│   └─ [00:08-00:09] 深呼吸(张华) | 1s | 近距离 | 气息可闻
│   └─ [00:15-00:16] 门轻轻关上 | 1s | 闷响 | 空间回声
│
├─ 语音层 (VOICE)
│   └─ [00:03-00:06] 张华: "你真的想好了吗?" | 3s | 压抑/不舍
│   └─ [00:07-00:10] 李明: "我没有选择。" | 3s | 平静/决绝
│   └─ [00:11-00:13] 张华: (沉默，哽咽) | 2s | 隐忍哭泣
│   └─ [00:14-00:15] 李明: "等我回来。" | 1s | 轻柔/承诺
│
└─ 音乐层 (BGM)
    └─ [00:00-00:03] 无音乐，纯环境音铺垫
    └─ [00:03-00:12] 钢琴独奏 | 55BPM | 悲伤/惜别 | 极轻音量
    └─ [00:05] 第一滴雨声+钢琴重音同步
    └─ [00:12-00:15] 弦乐渐入叠加钢琴 | 情绪升温
    └─ [00:15] 最后一个钢琴音+关门声同步fadeout
    └─ 节拍同步: 00:03;00:06;00:09;00:12  (每3秒一拍)
```

## 七、使用规则

### 音频优先级
1. **台词 > 环境音 > 音效 > 音乐**：对话场景音乐应让路
2. **音乐渐入渐出**：进入/退出音乐需有至少1秒淡入淡出
3. **音量动态**：紧张场景可渐强，悲伤场景可渐弱
4. **留白设计**：关键对话前留1-2秒纯环境音，引出沉默张力

### 即梦/Jimeng 音频适配
- 当前即梦主要支持：环境音保留、BGM控制
- SFX精确时间码：作为导演意图标注，供后期制作参考
- 音乐节拍：标注剪辑同步点，供专业后期使用
- 语音层：确保台词完整性与情感标注

### 禁止事项
- 禁止新增未授权音效（如版权音乐片段）
- 禁止凭空创造物件音（必须基于画面中可见物件）
- 禁止在安静场景强加环境音（尊重沉默的张力）
