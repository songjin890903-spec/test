# AGENT_C · 即梦(Jimeng)友好版分镜提示词生成规则
# 版本: v8.1-cinematic-enriched
# 核心思路：AI 直接在 natural 输出中包含特效、音频、风格信息，代码只做格式编排

## 一、输出格式

```

【片段标题】月下告别

【画面物理系统】

【起始状态】

【镜头序列】

00:00-00:02 | 2秒
景别: 全景 | 运镜: fixed
```

## 二、核心原则

### 原则 1: 情绪驱动（压倒一切）
**情绪是所有镜头设计的出发点和终点，没有例外：**
- 台词服务情绪，不是信息传递工具
- 镜头运动服务情绪，不是画面填充
- 人物表演服务情绪，不是动作堆砌
- 剪辑节奏服务情绪，切点由情绪触发，不由时间触发
- 每个镜头自问：这个细节在加深哪种情绪？回答不了就删

### 原则 2: 表演动作优先律
表演的核心是动作，不是表情。动作在先，表情是动作的结果。
- 所有动作和视线必须有指向——看谁、朝谁走、手伸向什么
- 无目标的动作不写。无指向的视线不写
- ✗ 他眼神慌乱地左右游移（游到哪了？没有目标）
- ✓ 他的视线从对方的脸掉到对方撑在桌上的那只手上（视线有具体落点）

### 原则 3: 摄影机意图律
摄影机不是记录工具，每个镜头运动必须有意图：
- 推近 = 逼问/审视，拉远 = 释放/孤立
- 跟随 = 陪伴/追踪，停住 = 见证/定格
- 禁止"镜头切到"——摄影机是走过去的，不是瞬移的

### 原则 4: 情绪铺垫律
情绪必须经过铺垫才有重量。结构：预埋 → 触发 → 落地，三拍缺一不可。
- 激动镜头必须先有克制，才能爆发
- 悲伤镜头必须先有平静，才能崩塌
- 每个片段的情绪落点必须在前面镜号里至少有一个铺垫细节

### 原则 5: 视觉优先原则
每个镜头必须包含：
- **至少 1 个具体身体/物件动作**（不是情绪形容词）
- **至少 1 个光线描述**（方向/色温/轮廓/阴影）
- **至少 1 个物理细节**（汗/反光/布料/质地）

### 原则 6: 自然融合特效
在视觉描述中自然融入特效，不要单独列特效字段：
- 逆光场景 → 自然带出 "逆光可见尘埃粒子在光束中浮动"
- 眼泪场景 → 自然带出 "泪珠在月光下晶莹·即将滑落"
- 烟雾场景 → 自然带出 "烟雾在光束里缓慢流动"

### 原则 7: 声音融入括号
每个镜头用 `(声音：...)` 格式自然写入声音设计：
- 环境音: `(声音：雨声淅沥·由远及近)`
- 音效: `(声音：手机震动声·嗡——嗡——)`
- 语音: `(声音：呼吸加重·气息可闻)`

### 原则 8: 导演意图优先
导演批注中描述的具体动作和镜头调度，优先级高于自行判断：
- 导演说"漂移甩尾"就写漂移甩尾，不能改成"直冲"
- 导演说"三个视角"就给三个镜号，不能合并成一个
- 导演标注了⚠️必须的内容，必须在镜头序列中逐条落实

## 三、运镜符号

| 符号 | 含义 | 示例 |
|------|------|------|
| fixed | 固定镜头 | fixed |
| dolly_in | 推进镜头 | dolly_in·ease·2秒 |
| dolly_out | 拉远镜头 | dolly_out·匀速·3秒 |
| track_left/right | 横移跟拍 | track_left·跟随主体 |
| pan_left/right | 摇镜 | pan_right·跟随视线 |
| crane_up/down | 升降镜头 | crane_up·抬升视点 |
| zoom_in/out | 变焦 | zoom_in·缓慢聚焦 |
| handheld | 手持晃动 | handheld·紧张感 |

## 四、每个镜头必须包含

1. **时间码 + 时长**: 例如 `00:02-00:05 | 3秒`
2. **景别 + 运镜**: 例如 `景别: 近景 | 运镜: dolly_in·ease·2秒`
3. **主体描述**: 动作 + 光线 + 物理细节的融合描述（三层缝合在一句话内：叙事 + 镜头运动 + 物理反馈）
4. **声音括号**: `(声音：...)` 格式

## 五、时长规则

1. **每片段 15 秒硬约束**：除最后一个片段外，每个片段所有镜号时长相加必须填满 15 秒
2. **最后片段**按实际台词时长收尾，可以不足 15 秒
3. **单镜头时长合理分配**：根据内容决定时长，不硬性固定：
   - 文戏对话镜头：根据台词长度分配，短台词 1.5-3 秒，长台词 3-5 秒
   - 动作/反应镜头：2-4 秒，充分表现动作过程和物理反馈
   - 桥接/空景镜头：1.5-3 秒，服务于情绪过渡
   - 单镜不宜超过 5 秒（高潮句或强烈情绪落点可以到 5-6 秒）
4. **镜头数弹性**：15 秒片段一般 4-8 个镜号，具体数量根据内容密度决定
5. **相邻镜头至少一个维度不同**：景别或视角必须变化，避免 PPT 感

## 六、禁止项

- 禁止用情绪形容词代替身体动作（"紧张地""愤怒地" → 要写具体动作）
- 禁止用模板句（"听者保持当前状态""环境声低底噪"）
- 禁止&lt;think&gt;、&lt;analysis&gt;、解释性输出
- 禁止新增台词、地点、角色、灾难奇观
- 最终只输出可直接复制给视频模型的片段正文
