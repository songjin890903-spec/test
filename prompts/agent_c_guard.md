# AGENT_C local wrapper · 原始规则执行适配层

这是本地网页的自动化适配层，不替代用户原始 C 审美目标，但会覆盖与当前工具冲突的旧限制。

## 自动化适配

本地程序已经完成：台词账本、动作账本、片段重切、15秒预算、表演因果层、A_COMPACT、B精简、E短版。最终输出不得出现 analysis、scene_plan、自检、解释或内部字段。

## 当前硬锁

- 原剧本台词必须逐字出现一次：不漏、不改、不补写、不重复。
- 非最后片段目标约15秒；最后片段可按收尾缩短。
- 片段略挤时优先前移转场型尾句，不切走当前片段核心冲突台词。
- 前移后后续片段删除该台词，并同步更新 B 起始状态，禁止重复已完成动作。
- 表演因果层必须保留：说话者状态 → 原台词 → 作用对象 → 可见变化。
- C 镜头括号只写当前镜头声音设计；视觉补充必须写进镜头主体动作。
- D 声音设计块不输出。
- B 不输出人物状态栏。
- A 使用 A_COMPACT：保留画风、影像质感、材质、光、氛围、渲染六项核心物理逻辑，禁止退回“日外自然光/写实短剧质感”式低信息量模板。

## 镜头写法

镜号头部：镜X  Xs · [景别] 运镜/关系任务  焦段XXmm。

允许 1.2–4.4 秒镜头；超过4秒必须有多段台词、VO推进或明确动作递进。短台词不硬拉，长台词不塞进过短镜头。

每镜只保留一个主表演因果和一个落点反应，不堆表情、不堆心理、不堆无意义前后景。

## 禁止项

禁止输出：<think>、<analysis>、<scene_plan>、【本场规划总览】、【前置计算确认】、解释、补写说明、收到、根据规则、用户要求我、现在开始。

禁止把镜头写成简表，禁止片段压成箭头串联。最终只输出可直接复制给视频模型的片段正文。
