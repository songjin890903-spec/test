# 2026-05-18 工作日志

## Physics算法引擎重构（structuredC.js）

**改造内容**：

1. **新增 derivePhysics() 算法推导引擎**（lib/structuredC.js，约350行）：
   - `inferPhysicsFromSceneHeader()` — 从场景头推导时间/地点/天气物理
   - `inferPhysicsFromAnnotation()` — 从AI批注剧魂定位卡推导视觉风格
   - `parseDirectorPhysics()` — 导演讲戏关键词→physics映射表（DIRECTOR_PHYSICS_MAP）
   - `mergePhysicsLayers()` — 三层合并：sceneHeader < annotation < directorNotes（优先级递增）
   - `derivePhysics()` — 主入口，替代 defaultPhysics 硬编码

2. **导演讲戏→physics关键词映射表**（DIRECTOR_PHYSICS_MAP）：
   - 压抑/沉重 → 死寂空气+极低照度
   - 浪漫/暧昧 → 暖暗光+薄雾
   - 冷调/蓝 → 冷白光+青灰氛围
   - 暖调/夕阳 → 暖橙色光+金黄氛围
   - 逆光/剪影 → 强烈逆光+轮廓分离
   - 胶片感 → 强颗粒+晕光
   - 复古/年代 → 旧材质+风化痕迹
   - 快节奏 → 手持感+快切节奏
   - 等20+种风格关键词

3. **createSegmentSkeleton() 支持新参数**：
   - 新增 `{ annotation, directorNotes }` 选项对象
   - 有 annotation/directorNotes 时优先调用 derivePhysics，否则兜底 defaultPhysics

4. **buildBatchEnrichPrompt() 增强上下文**：
   - 新增 `directorSummary` — 导演讲戏摘要（前500字）注入场景信息区
   - 新增 `annotationSummary` — AI批注摘要（剧魂定位卡+场景批注）注入

5. **全链路打通**：
   - pipeline.js: runAgentC → directorNotes透传 → enrichSegmentShots
   - server.js: 两个API端点 → directorNotes透传
   - buildSegmentJsonUser → 新增 annotation/directorNotes 参数

**向后兼容**：无 directorNotes 时完全走旧硬编码，不影响现有流程。

**验证**：三种directorNotes风格测试通过，physics输出正确区分。

## abc-video-tool 导演意图感知修复（20:30完成）

**根因**：`planSceneSegments` 只看台词/动作边界，完全不感知批注文本中的导演意图片段数，导致算法算出1段、导演映射了15段时，15个导演意图被全丢。

**修复方案**：
- `segmentPlanner.js` 新增导演意图感知逻辑，从 `opts.annotatedScript` 提取批注块，统计"（导演讲戏：...）"括号数量
- 当导演块数 > 算法片段数时，按意图列表拆分片段
- `pipeline.js` 将 `annotatedScript`（即 `cleanA`）透传给 `planSceneSegments`
- 每个片段携带 `directorIntent` 字段，供后续 enrichment 阶段参考

**修改文件**：`lib/segmentPlanner.js`、`lib/pipeline.js`
